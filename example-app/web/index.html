Express Light Rail example

Discussion Board API

This example exposes a JSON API for users, discussion threads, and comments. The API is protected; send your configured demo identity or a verified bearer token with API requests.

Service health

Check the database-backed service status

Explore the API

  • GET /api/users
  • GET /api/threads
  • GET /api/threads/:threadId/comments

For example, in demo mode:

curl -H 'x-user-id: alice' http://localhost:3000/api/threads

Use a bearer token instead when the example is configured for Auth0.
