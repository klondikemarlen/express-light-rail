Discussion Board API

This example exposes a JSON API for users, discussion threads, and comments. Log in with a username and password to receive a short-lived bearer token, then send it with protected API requests.

Explore the API

  • GET /api/users
  • GET /api/threads
  • GET /api/threads/:threadId/comments

Log in using a seeded development account:

curl -H 'content-type: application/json' \
  -d '{"username":"alice","password":"alice-password"}' http://localhost:3000/api/session
curl -H "Authorization: Bearer $ALICE_TOKEN" http://localhost:3000/api/threads

Set ALICE_TOKEN to the returned accessToken. It expires after 15 minutes. Auth0 is a common alternative wired at the same authentication boundary; no external identity provider is required for this example.
